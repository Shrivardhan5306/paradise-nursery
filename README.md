\# Paradise Nursery Shopping Application



\## Project Overview



Paradise Nursery is an online houseplant shop built with React and Redux Toolkit.



\## Features



\- Landing page with company information and a Get Started button

\- Eighteen houseplants grouped into three categories

\- Plant images, names, and prices

\- Add-to-cart buttons that disable after adding a product

\- Navigation links to Home, Plants, and Cart

\- Dynamic shopping cart item count

\- Increase and decrease product quantities

\- Remove items from the cart

\- Individual item totals and overall cart total

\- Continue Shopping button

\- Checkout Coming Soon message

\- Responsive layout for desktop and mobile devices



\## Technologies



\- React

\- Vite

\- Redux Toolkit

\- React Redux

\- CSS



\## Run Locally



Install dependencies:



&#x20;   npm install



Start the development server:



&#x20;   npm run dev
